# 🏠 Florida Real Estate Master Drill: Minimalist Edition

A high-velocity, distraction-free exam engine built for Florida Real Estate candidates. This edition strips away the noise to focus on pure retention, featuring a **Neo-Brutalist** design and a high-performance vanilla JavaScript core.

## ⚡ High-Velocity Features

  * **🦴 Neo-Brutalist Design:** A "Paper-on-Slate" aesthetic using high-contrast borders, tactile 3D shadows, and a clean off-white palette to reduce eye strain during long study sessions.
  * **⏱️ Quick 20 Mode:** A randomized "sprint" mode that shuffles your 146-question bank and slices it down to 20 items for rapid-fire review.
  * **⌨️ Keyboard-Native Workflow:** Designed for power users. Drill through questions without touching your mouse:
      * **[1, 2, 3, 4]**: Select your answer choice.
      * **[Enter]**: Advance to the next question once feedback is shown.
  * **💾 State Persistence:** Uses `localStorage` to save your session. If you refresh or close the tab, the **Resume** button restores your exact question index, score, and timer.
  * **📊 Category Mastery:** Real-time tracking of your performance across the 13 official Pearson VUE categories.
  * **🎉 Confetti Engine:** Built-in celebration logic for passing scores (75%+) to maintain high motivation.

## 🧮 Integrated Reference Modal

The minimalist reference modal provides instant "at-a-glance" access to the most tested Florida formulas:

  * **Transfer Taxes:** Doc Stamps ($.70), Note Stamps ($.35), and Intangible ($.002).
  * **Land Measurement:** Acreage (43,560) and Section (640 Acres) constants.
